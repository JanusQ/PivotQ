## 系统介绍

PivotQ 用于编写和运行跨 **CPU、GPU、QPU** 的混合计算任务。编程框架组织任务执行，性能模拟器估算不同硬件配置下的运行时间，可视化操作界面用于配置应用和查看结果。[了解系统设计与组成](./architecture/)

| 组成 | 用途与关系 |
| --- | --- |
| 门户网站（当前网站） | 阅读文档、代码和已保存的演示数据，不提交计算任务。 |
| Python 编程框架 | 在运行环境中组织 CPU、GPU、QPU 任务及数据依赖。 |
| 性能模拟器（QPerfSim） | 根据任务工作量和目标设备参数估算耗时。 |
| Linux 可视化操作界面（历史名称“工作台”） | 在 Linux 启动服务后，通过浏览器配置应用、预测耗时、提交任务和查看结果。 |
| 水分子动力学应用（H₂O AIMD） | 操作界面中的一个应用示例，使用量子—经典代理势能模型；不是整个 PivotQ 系统的名称。 |

首页的水分子示例展示 CPU、QPU、GPU 的任务分工：QPU 运行电路，GPU 预测势能，CPU 处理输入、测量结果、受力和位置更新。工作台教程截图对应的是 CPU 数值模拟任务；两者不是同一次运行记录。

## 启动 Linux 可视化操作界面

先在 Linux x86-64 环境按 [Docker 安装与启动说明](./installation/#使用-docker-安装)启动 PivotQ 服务，再在同一台机器的浏览器打开 `http://127.0.0.1:8787/`。界面中的“工作台”用于编写与配置，“性能预测”用于估算耗时，“结果中心”用于查看运行记录与结果。

`127.0.0.1` 始终指浏览器所在的机器。若服务运行在远程 Linux 主机，请先按部署环境建立 SSH 端口转发，再打开本机对应地址。门户网站与 Linux 服务是两个入口；点击教程不会启动服务。
