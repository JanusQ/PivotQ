## 最小混合程序

[快速上手](../quickstart/)直接展示仓库内完整可执行的 Python 教程代码。它不依赖水分子应用：先由经典任务生成电路，再由模拟器执行采样，最后由经典任务分析结果。

## CPU、GPU 与 QPU 协作

[GPU 与异构资源](../gpu-computing/)介绍仓库中的 CUDA 组件和 CPU → GPU → QPU 客户端验证流程，并说明 Ray 资源声明、运行环境与 GPU 性能预测入口。该验证使用固定响应的 QPU 测试后端。

## 水分子动力学模拟

[水分子动力学模拟](../../examples/aimd/)展示量子-经典势能模型、计算步骤与已保存的轨迹，并提供 Linux 可视化操作教程入口。播放控件只重播已有数据，不提交在线计算。

## 量子随机存取存储器

[量子随机存取存储器](../../examples/qram/)提供概念、寻址示意与可在本机运行的教学程序，通过 PivotQ 构造电路，再用 Qiskit `Statevector` 计算理想态矢量。它不提交 PivotQ 作业，没有量子随机存取存储器真机读写或测量结果，不能作为 SDK 验收程序。
